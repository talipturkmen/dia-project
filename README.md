# Data Intelligence Applications Project

> **Archived.** This is a 2020 university course/learning project and is no longer maintained.

A team project for a Data Intelligence Applications course (with Anne and Alireza, Julian, Talip). It simulates online advertising: a publisher allocates ads to slots by solving a bipartite matching problem (Hungarian algorithm), and an advertiser learns unknown click probabilities and allocates its daily budget across subcampaigns with bandit algorithms (a Gaussian Process learner, GPTS, and a knapsack-based budget allocation). The code builds a synthetic environment, runs the learning experiments over a time horizon, and saves plots of the cumulative regret and the environment's aggregated click curves.

## Tech stack

- Python 3
- NumPy, SciPy (`linear_sum_assignment` for the matching step)
- scikit-learn (Gaussian Process regression used by GPTS)
- matplotlib (plots)

## Repository structure

- `run.py` - entry point; builds the environment and runs the experiments
- `configuration/config.py` - subcampaign, user-class and click-probability parameters
- `environment/` - campaign classes, environment and subcampaign models
- `distributions/` - Gaussian, uniform and generic probability distributions
- `learner/GPTS.py` - Gaussian Process Thompson Sampling learner
- `algorithms/` - Hungarian matching and knapsack solvers
- `experiment/` - experiment loop and per-subcampaign slot algorithm
- `utilities/` - environment building, rounding, partitioning, printing and plotting helpers
- `config.py` - older configuration file, marked unused in its own comments (the live config is in `configuration/`)
- `class.py` - standalone `Class` definition, not imported by other modules
- `Imagination` - scenario notes as a plain Python file (not imported by `run.py`)
- `plots/` - aggregated environment plots from a previous run (regenerated by `run.py`)

## How to run

From the repository root:

```
pip install -r requirements.txt
python run.py
```

Plots are written to `plots/`. The script runs the full experiment, which can take a while.
